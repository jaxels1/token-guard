5-layer token defense without breaking your KV cache.

Token Guard (token-guard) equips Antigravity, Claude Code, Cursor, Codex, and Gemini CLI with deterministic read deduplication, noisy command output compression, a cache-safe <350-token skill, and a JSONL transcript auditor. 

npx skills add jaxels1/token-guard

5 Defense Layers

read_guard.py

Blocks unchanged duplicate reads, covered subranges, lockfiles, minified bundles, and >500-line unbounded reads.

cmd_filter.py

Compresses verbose test, build, lint, and git output with exact exit codes and full raw temp-log spills.

Cache-Safe SKILL.md

Under 350 tokens with parallel tool batching, symbol-first navigation, and zero per-turn PreInvocation cache invalidation.

audit_transcript.py

Parses Antigravity & Claude Code JSONL transcripts to quantify duplicate reads blocked and net tokens saved.
