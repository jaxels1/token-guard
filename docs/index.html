5-layer token defense without breaking your KV cache.

Token Guard (token-guard) equips Antigravity, Claude Code, Cursor, Codex, and Gemini CLI with deterministic read deduplication, noisy command output compression, a cache-safe <350-token skill, and a JSONL transcript auditor. 

npx skills add jaxels1/token-guard

5 Defense Layers

read_guard.py

Blocks unchanged duplicate reads, auto-trims overlapping ranges, and gates lockfiles, minified bundles, and >500-line unbounded reads.

cmd_filter.py

Compresses verbose test, build, lint, and git output (including cd / PowerShell Set-Location prefixes) with raw temp-log spills.

Cache-Safe SKILL.md

309 tokens with parallel tool batching, symbol-first navigation, and zero per-turn PreInvocation cache invalidation.

audit_transcript.py

Parses Antigravity, Claude Code & ChatGPT / Codex JSONL transcripts to quantify duplicate reads blocked and net tokens saved.

Verified Benchmark Proof (63 Real Sessions · 15,024 Tool Calls)

-55.5% Uncached Burn

Eliminated 14.75M tokens (59.0 MB) out of 26.56M fresh uncached input tokens across 63 ChatGPT / Codex Desktop sessions (~2.25× quota runway).

-80.7% Output Bloat

Compressed oversized and noisy command/tool output across 15,024 calls from 47.61 MB down to 9.17 MB while preserving errors and exit codes.

2,951 Duplicate Reads

Caught 2,951 unchanged duplicate file reads across 63 ChatGPT / Codex sessions plus 7 duplicate reads (`~15,825` tokens) in a 610-turn Antigravity session.

97.8% KV Cache Hit

Zero PreInvocation prompt mutations kept 1.190B of 1.217B input tokens served straight from the KV prefix cache.
