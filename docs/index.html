5-layer token defense without breaking your KV cache.

Token Guard (token-guard) equips Antigravity, Claude Code, Cursor, Codex, and Gemini CLI with deterministic read deduplication, noisy command output compression, a cache-safe <350-token skill, and a JSONL transcript auditor. 

npx skills add jaxels1/token-guard

5 Defense Layers

Compaction-Aware read_guard

Resets on PreCompact, auto-trims overlapping ranges, provides a 2nd-try escape hatch, and returns automatic AST/regex symbol outlines on >500-line files.

Allowlist-Friendly cmd_filter

Preserves command prefixes (<cmd> 2>&1 | python3 cmd_filter.py --pipe), delegates to rtk when installed, and spills raw logs to %TEMP%.

search_guard & Sub-2ms Daemon

Caps monorepo rg / Grep explosions at 80 matches (excluding node_modules & lockfiles) and serves hooks from a persistent worker (p50 = 1.95 ms).

Live A/B + Replay Auditors

Ships both a 24-task live A/B harness (ab_benchmark.py, modeling rebound calls) and a JSONL transcript auditor (audit_transcript.py).

Live 24-Task A/B Benchmark + 63-Session Replay Audit

24/24 Pass · -95.0% in Live A/B

Across 24 deterministic tasks in ab_benchmark.py (including 6 rebound slice reads after AST outlines): 100% task pass rate and 443,112 → 22,292 fresh tokens.

p50 = 1.95 ms Hook Latency

Persistent background worker (hook_daemon.py) keeps state hot in memory over a TCP_NODELAY socket, cutting per-call hook latency to 1.95 ms median.

-55.5% Replay Recoverable Burn

Offline replay across 63 ChatGPT / Codex sessions (15,024 calls) identified 14.75M recoverable tokens (59.0 MB) out of 26.56M fresh uncached input tokens.

2,951 Dup Reads & -80.7% Output

Flagged 2,951 duplicate file reads and compressed oversized tool outputs from 47.61 MB to 9.17 MB while preserving a 97.8% KV cache hit rate.
